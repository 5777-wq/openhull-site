CAPABILITIES

它做什么

从任务书到交付物，九个环节全部自动化——每一条经验公式都有白名单出处。

DIMENSIONS

主尺度与重量

载重量比法估算、诺曼系数迭代的重量浮力平衡，输出主尺度方案与载重量比。

HULL FORM

参数化船型

数字化 Series 60 母型 + Lackenby 变换，交付真实型值表与分层 DXF 型线图。

HYDROSTATICS

静水力

静水力表、邦戎曲线，自动绘制教材版式静水力曲线图（12 项要素）。

STABILITY

稳性校核

大倾角 GZ 曲线 + IMO 2008 IS Code 2.2 六项衡准 + 恶劣风浪衡准 2.3，逐条判定。

PERFORMANCE

阻力与推进

艾亚阻力估算、Holtrop 推进因子、瓦根宁根 B 系列螺旋桨设计与空泡校核。

OPTIMIZE

方案空间扫描

L/B × B/T × Cb 网格逐点过全链：可行方案集、逐级拒绝记录、帕累托前沿。

SEAKEEPING

耐波性两级

书内公式固有周期与谐摇判定；可选 capytaine 扩展输出零航速 RAO 曲线。

SPEED LOSS

失速估算

Kwon 方法：按蒲福风级、浪向与装载状态估算波浪中航速损失与实际航速。

DELIVERABLES

图纸与报告

静水力曲线图、总布置简图（图+分层 DXF）、中文 Markdown 设计报告，一条命令出齐。

QUICK START

三步跑通

需要 Python ≥ 3.11；RAO 功能为可选扩展（capytaine），不装不影响其余功能。

① 安装
# 方式一：uv（推荐）
git clone https://github.com/5777-wq/OpenHull.git
cd OpenHull
uv sync

# 方式二：pip
pip install -e .
# 耐波性 RAO 可选扩展：
pip install -e '.[seakeeping]'
② 写任务书，跑一条命令
# 仓库自带 25 万吨级散货船示例任务书（JBC 基准船锚定）
openhull run examples/taskbook_bulk_carrier.yaml \
    --report design_report.md \
    --hydro-curve-chart curves.png \
    --arrangement-chart ga.png \
    --arrangement-dxf ga.dxf
③ 拿成果
design_report.md   # 中文设计报告（稳性逐条判定/耐波性/分舱表）
curves.png         # 静水力曲线图（教材版式 12 要素）
ga.png / ga.dxf    # 总布置简图与分层 DXF
# 方案扫描与 RAO：
openhull optimize 任务书.yaml      # 192 方案 → 64 可行 → 帕累托前沿
openhull rao 任务书.yaml           # 顶浪/横浪垂荡·横摇·纵摇 RAO

PRINCIPLES

把工程纪律写进章程

这四条写在项目章程（AGENTS.md）里，AI 智能体和贡献者都必须遵守。

① 白名单先行

经验公式先入 AGENTS.md §5 白名单、对照原书页面核验后才能实现——先立账本再动手。

② 验收靠数字

书上算例、独立路径互检、公开基准船数据；"能跑"不算验收。

③ 近似必须声明

直壁甲板、阻尼区间、被约束的自由度——写了什么假定，就声明在哪里。

④ 人机各司其职

谐摇区是否规避、衡准是否否决方案，是船舶工程师的专业判断；工具只报告，不拍板。
